Image Viewer Integrity Evaluation System (IVIES)
==================================================
The Image Viewer Integrity Evaluation System (IVIES) for whole slide imaging devices  is a Medical Device Development Tool (MDDT) and is categorized as a Non-clinical Assessment Model (NAM). It is a non-clinical, colorimetry-based test method that measures the device performance of pathology whole slide image viewing software devices to determine the need for additional performance study. The MDDT is not an FDA-cleared or approved medical device. The official [MDDT summary](https://www.fda.gov/media/191032/download?attachment) can be found at https://www.fda.gov/medical-devices/medical-device-development-tools-mddt. 

# Context of Use
The Image Viewer Integrity Evaluation System (IVIES) is a software tool qualified to assist with assessing whether a pathology whole slide image viewing software device can decode the same input image file and display pixelwise identical images when compared to the predicate whole slide imaging device image review manipulation software. The IVIES tool quantitatively measures the differences between two images by calculating their colorimetric difference for each pixel. The colorimetric pixel differences can be used as a quantitative measure to compare the performance of two whole slide image viewing software devices and to determine whether additional clinical study data is needed to further characterize the performance of the device.

IVIES is not suitable for evaluation of third-party viewers that intentionally alter the image rendering or the downstream components such as the computer environment or the display system.

# Install IVIES

## System Requirements

| Component | Requirement |
|-----------|-------------|
| Operating System | Windows 10 or later (64-bit) |
| MATLAB Runtime | R2023a (9.14a) |
| Memory (RAM) | 8 GB minimum, 16 GB recommended |
| Storage | Varies based on dataset size; recommend 50 GB free space on a local or network drive |
| Permissions | Administrator rights for installation of the MATLAB Runtime; permission to execute the downloaded .exe application |

## Install the MATLAB Runtime Library

The MATLAB Runtime R2023a (9.14a) library must be installed before running the compiled IVIES executable. The library is freely available for downloading at:

https://www.mathworks.com/products/compiler/matlab-runtime.html

### Installation Steps:

- Download MATLAB Runtime R2023a (9.14a)

  > **ⓘ NOTE:** Only the R2023a (9.14a) version can be used because the MATLAB Runtime version must match the compiled app.

- Run the MATLAB Runtime installer and follow the on-screen instructions

  > **ⓘ NOTE:** Installing the MATLAB Runtime does **not** need a MATLAB license.

- Verify installation at: `C:\Program Files\MATLAB\MATLAB Runtime\R2023a`

## Get the IVIES App

Download the IVIES app:

- Visit https://github.com/DIDSR/ivies/bin
- Download the executable file: `IVIES_02202026.exe`
- Save the file to a convenient location on the computer
- No installation required - the application runs directly from the executable

# Sample Dataset 
A simplified sample dataset for demonstration purposes. In the “demo” folder, there are 3 subfolders:
- `demo/input/predicate` contains 48 test images generated by the predicate viewer
- `demo/input/subject` contains 48 test images generated by the subject viewer 
- `demo/overview` contains 8 WSI overview images showing the ROIs
